# LM Studio 简体中文深度汉化补丁

适用于 **LM Studio 0.4.20+1 和 0.4.26+4 / Windows x64** 的非官方简体中文增强补丁。

补丁不包含 LM Studio 主程序、Renderer Bundle、模型、用户数据或密钥。安装器依据实际 `main_window.js` SHA256 选择版本，未知版本会拒绝修改。

|---|---|---|---|

| 0.4.26+4 | `2A01446F852812338A204ADB539BF6E00689FAAF61F664F1E38BD13ED6D3ADFE` | `0DF640E5460FEA7B97DA21FCD93735AF34D03BF24669E64F58379F74972ABF31` | `.zh-cn-deep-0.4.26-4.bak` |

0.4.20+1 保留原有 87 项官方词库补全、227 项深度映射、动态翻译、备份、升级、哈希检查、原子替换和恢复逻辑。0.4.26+4 使用独立版本配置、独立 Overlay 和独立哈希，不复用未经验证的补丁产物。

## 汉化范围

- 保留原项目 227 项固定界面翻译和原有官方中文词库资源；
- 为 0.4.26+4 增加 6 项官方 locale 配置翻译和 39 项固定 UI/动态文本翻译；
- 覆盖聊天、侧栏、设置、模型默认设置、运行时、硬件、LM Link、Model Server、Library、模型搜索和开发者页面；
- 保留模型名称、模型简介、API 路径、参数、代码、命令、日志和用户输入；
- 动态处理 GPU 数量、CUDA 引擎版本、显存标签、模型数量、相对日期和下载大小等界面文本。

## 安装

1. 完全退出 LM Studio，包括系统托盘中的进程。
2. 解压发布 ZIP。
3. 双击 `01_install_patch.cmd`。
4. 如果安装器没有自动找到目标目录，可以把 LM Studio 安装目录作为脚本参数传入。
5. 启动 LM Studio，并在设置中选择简体中文。

安装器会依次检查进程、版本、目标文件、原始 SHA256、备份状态、候选文件哈希和写入结果。失败时不会绕过检查，并会尝试从已验证备份恢复。

## 恢复

完全退出 LM Studio，双击 `02_restore_original.cmd`。恢复前会验证对应版本的备份 SHA256，恢复后会再次验证原始文件哈希。

## 目录结构

- `baseline/zh-CN/`：原项目官方中文基线；
- `payload/zh-CN/`：兼容版本的中文词库；
- `deep/deep-overlay.js`：0.4.20+1 Overlay；
- `deep/deep-overlay-0.4.26-4.js`：0.4.26+4 Overlay；
- `source/deep-ui-zh-CN.json`：原有 227 项映射；
- `source/deep-ui-zh-CN-0.4.26.json`：0.4.26+4 映射；
- `versions/`：版本、路径、哈希和备份配置；
- `scripts/`：安装、恢复、提权和回滚逻辑；
- `tests/`：静态资源和安装恢复测试。
